# Student Performance Prediction System

## Objective

Predict a student's final mathematics grade using the UCI Student Performance dataset.

## Dataset

This project uses only the Mathematics file, `data/student-mat.csv`, from [UCI Student Performance, dataset 320](https://archive.ics.uci.edu/dataset/320/student%2Bperformance). The source CSV uses semicolons as separators. It contains 395 rows and 33 columns.

## Target and features

The target is `G3`, the final grade on a 0–20 scale. The model uses these 30 input features:

`school`, `sex`, `age`, `address`, `famsize`, `Pstatus`, `Medu`, `Fedu`, `Mjob`, `Fjob`, `reason`, `guardian`, `traveltime`, `studytime`, `failures`, `schoolsup`, `famsup`, `paid`, `activities`, `nursery`, `higher`, `internet`, `romantic`, `famrel`, `freetime`, `goout`, `Dalc`, `Walc`, `health`, `absences`.

`G1` and `G2` are excluded to prevent grade leakage. `G3` is excluded from inputs because it is the target. The script checks data types, missing values, duplicates, documented value ranges, and confirms these grade columns are not features. The source data has no missing or duplicate rows; valid outliers are retained.

## Algorithm and preprocessing

One `RandomForestRegressor` is used with 300 trees, `random_state=42`, and `n_jobs=-1`. The numerical pipeline imputes with the median. The categorical pipeline imputes with the most frequent value and one-hot encodes unknown-safe categories. Both are fitted as part of the Scikit-learn pipeline using training data only. No scaling is used.

## Evaluation

The fixed split is `test_size=0.20`, `random_state=42` (316 training rows and 79 untouched test rows). Actual test metrics from `src/train.py`:

| Metric | Result | Meaning |
|---|---:|---|
| MAE | 3.009494 | Average absolute grade error |
| RMSE | 3.761327 | Error measure that penalizes larger misses more |
| R² | 0.310044 | Fraction of test target variation explained by the model |

See `results/evaluation_results.txt` for the run's sample actual/predicted values and range check. The test predictions were all within 0–20 before clipping. Regression predictions returned to callers are clipped to the valid grade range at the final prediction step.

## Train the model

From the project root:

```bash
python -m pip install -r requirements.txt
python src/train.py
```

Training saves the full preprocessing-plus-model pipeline to `model/student_performance_model.joblib` and the expected input fields to `model/feature_schema.json`. Re-running uses the same dataset and random seed.

## Prediction and Flask handoff

`src/predict.py` exposes `predict_student(student_data)`. Input must be a JSON-style dictionary with exactly the 30 feature keys listed above, using the dataset's categorical strings and numeric values. Do not send `G1`, `G2`, or `G3`. Extra or missing fields raise a clear `ValueError`.

From the project root, a Python caller can use:

```python
from src.predict import predict_student

result = predict_student(student_data)
print(result)  # Output shape: {"predicted_grade": <number>}
```

The input contract is the exact feature dictionary in `sample_input.json`. The output contract is `{"predicted_grade": <number from 0 to 20>}`. For the included sample input, the saved model returns `{"predicted_grade": 9.49}`; `sample_output.json` was generated by loading the saved pipeline and predicting that input. A Flask route can parse its JSON body, call `predict_student(body)`, and return that dictionary as JSON; Flask itself is outside this project.
